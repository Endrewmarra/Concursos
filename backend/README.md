## Tecnologia prevista

- Python
- FastAPI

## Responsabilidades

- Autenticação
- Gerenciamento de concursos
- Cadastro de candidatos
- Controle dos jurados
- Registro das notas
- Atualização da classificação em tempo real
- Exportação dos resultados
