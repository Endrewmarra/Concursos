
# Database

Esta pasta contém todos os arquivos relacionados ao banco de dados do projeto.

## Conteúdo

* **scema.sql**
* Script SQL contendo toda a estrutura do banco de dados.
* **schema.png**
  Diagrama do banco de dados.

## Tecnologias

* MySQL

## Objetivo

O banco foi modelado para atender inicialmente ao MVP do sistema, contemplando:

* Eventos
* Administradores
* Jurados
* Candidatos
* Notas

A estrutura foi pensada para permitir futuras expansões sem necessidade de remodelagem completa.
