# Documentação

Esta pasta concentra os documentos de análise, planejamento e organização do projeto.

```text
docs/
├── regas_de_negocio/

│
├── requisitos/
```

## Conteúdo

### regas_de_negocio

Contém as regras de negócio do concurso, independentes da solução tecnológica.

### requisitos

Contém os requisitos funcionais, requisitos não funcionais, escopo do MVP e histórias de usuário.

### roadmap

Contém o planejamento de evolução do projeto.

### wireframes

Espaço reservado para os desenhos e protótipos das telas.

### diagrams

Espaço reservado para diagramas técnicos e de modelagem.

### screenshots

Espaço reservado para capturas das telas do sistema em desenvolvimento.
