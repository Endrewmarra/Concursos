# Escopo do MVP

Este documento define o escopo da primeira versão funcional do sistema.

O objetivo do MVP é entregar uma solução simples e utilizável no evento, substituindo o processo manual de avaliação por fichas impressas e planilhas.

---

# Objetivo do MVP

Permitir que um concurso de cosplay seja conduzido localmente, com:

- Cadastro de candidatos;
- Seleção dos participantes da modalidade;
- Controle do candidato atual pelo administrador;
- Avaliação dos candidatos pelos jurados;
- Cálculo automático das médias;
- Classificação geral atualizada;
- Encerramento da modalidade com resultado final.

---

# Funcionalidades incluídas no MVP

## Administração

- Login simples para administrador;
- Painel administrativo;
- Cadastro de candidatos;
- Listagem de candidatos cadastrados;
- Seleção de candidatos participantes;
- Ordenação dos candidatos selecionados;
- Controle do candidato atual;
- Avanço para o próximo candidato;
- Visualização da média dos candidatos;
- Visualização da classificação geral;
- Visualização detalhada das notas de um candidato;
- Alteração manual de notas pelo administrador;
- Encerramento do concurso/modalidade.

---

## Jurados

- Login simples para jurados;
- Visualização do candidato atual;
- Visualização das imagens de referência;
- Preenchimento das notas;
- Envio da avaliação;
- Bloqueio de nova avaliação para o mesmo candidato.

---

## Banco de Dados

- Armazenamento dos candidatos;
- Armazenamento dos jurados;
- Armazenamento dos concursos/modalidades;
- Armazenamento das notas;
- Consulta das médias e classificações.

---

## Operação

- Funcionamento em rede local;
- Uso do notebook principal como máquina de execução;
- Acesso dos jurados por celular conectado à mesma rede.

---

# Funcionalidades fora do MVP

As funcionalidades abaixo não fazem parte da primeira versão, mas podem ser implementadas futuramente.

- Cadastro online de candidatos;
- Autoinscrição por link;
- Cadastro online de jurados;
- Login com Google;
- Recuperação de senha;
- Envio de e-mails;
- Hospedagem em nuvem;
- Múltiplos eventos simultâneos;
- Painel público de resultados;
- Histórico completo por usuário;
- Área do candidato;
- Upload online permanente de imagens;
- Sistema avançado de permissões;
- Critérios de desempate automáticos;
- Penalidades automáticas;
- Dashboard estatístico;
- Aplicativo mobile nativo.

---

# Critério de sucesso do MVP

O MVP será considerado bem-sucedido se permitir que o concurso seja realizado sem uso de fichas impressas e sem cálculo manual das notas.

Para isso, o sistema deve permitir:

1. Cadastrar candidatos;
2. Selecionar os participantes;
3. Exibir o candidato atual para os jurados;
4. Registrar notas;
5. Calcular médias;
6. Exibir classificação;
7. Encerrar o concurso com resultado final.
