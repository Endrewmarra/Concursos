# Requisitos Inversos

## RI01 - O sistema não realizará autoinscrição de candidatos no MVP

O cadastro de candidatos será feito manualmente pelo administrador.

## RI02 - O sistema não dependerá de internet no MVP

A primeira versão será executada em rede local.

## RI03 - O sistema não terá login por Google no MVP

O acesso será feito por credenciais previamente cadastradas.

## RI04 - O sistema não permitirá múltiplos concursos simultâneos

Apenas uma modalidade/concurso poderá estar em andamento por vez.

## RI05 - O sistema não terá área do candidato no MVP

Candidatos não acessarão o sistema diretamente.

## RI06 - O sistema não terá recuperação automática de senha no MVP

Credenciais serão gerenciadas manualmente pela organização.

## RI07 - O sistema não calculará penalidades automáticas

O regulamento atual não prevê penalidades.

## RI08 - O sistema não aplicará critério automático de desempate

Em caso de empate, a decisão será responsabilidade da organização.
