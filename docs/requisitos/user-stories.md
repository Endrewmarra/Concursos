
# Histórias de Usuário

Este documento apresenta histórias de usuário para orientar o desenvolvimento do MVP.

---

## Administrador

### US01 - Login do administrador

Como administrador, quero acessar o painel administrativo com usuário e senha para gerenciar o concurso.

---

### US02 - Cadastro de candidato

Como administrador, quero cadastrar candidatos para manter uma base de participantes disponível para o concurso.

---

### US03 - Seleção de participantes

Como administrador, quero selecionar quais candidatos participarão da modalidade atual para organizar o concurso corretamente.

---

### US04 - Ordenação de candidatos

Como administrador, quero definir a ordem de apresentação dos candidatos para controlar a sequência do concurso.

---

### US05 - Controle do candidato atual

Como administrador, quero avançar o candidato atual para que os jurados avaliem sempre a pessoa correta.

---

### US06 - Acompanhamento das notas

Como administrador, quero visualizar as médias dos candidatos para acompanhar o andamento da avaliação.

---

### US07 - Visualização da classificação

Como administrador, quero visualizar a classificação geral em tempo real para acompanhar o resultado parcial do concurso.

---

### US08 - Consulta detalhada do candidato

Como administrador, quero visualizar as notas individuais de um candidato para conferir como sua média foi formada.

---

### US09 - Alteração de nota

Como administrador, quero alterar uma nota registrada quando houver necessidade de correção.

---

### US10 - Encerramento do concurso

Como administrador, quero encerrar a modalidade para consolidar a classificação final.

---

## Jurado

### US11 - Login do jurado

Como jurado, quero acessar minha tela de avaliação com usuário e senha para registrar minhas notas.

---

### US12 - Visualização do candidato atual

Como jurado, quero visualizar o candidato atualmente em apresentação para avaliá-lo corretamente.

---

### US13 - Consulta às imagens de referência

Como jurado, quero visualizar as imagens de referência do personagem para comparar com a apresentação.

---

### US14 - Registro das notas

Como jurado, quero preencher as notas das categorias avaliativas para registrar minha avaliação.

---

### US15 - Envio da avaliação

Como jurado, quero enviar minha avaliação para que ela seja contabilizada na média do candidato.

---

### US16 - Confirmação de envio

Como jurado, quero receber uma confirmação após enviar as notas para saber que minha avaliação foi registrada.
