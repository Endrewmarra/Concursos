# frontend

Interface gráfica do sistema de gerenciamento de concursos.

## Tecnologia

- React

## Objetivo

Fornecer interfaces distintas para:

- Administrador
- Jurados

## Situação atual

Em desenvolvimento.

As telas atualmente planejadas são:

- Login
- Painel do administrador
- Painel do jurado
- Cadastro de candidatos
- Lista de candidatos
- Detalhes do candidato

A comunicação com o banco de dados será realizada futuramente através da API desenvolvida em Python/FastAPI.
